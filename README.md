# Meu Primeiro PR

Este é um repositório de prática para aprender o fluxo de Pull Requests no GitHub.

## Sobre

Este projeto foi criado para exercitar o processo de:

1. Criar um repositório
2. Criar uma branch
3. Fazer uma alteração pequena e segura
4. Abrir um Pull Request

## Como contribuir

Sinta-se livre para fazer um fork e enviar sugestões atraves de Pull Requests.
